# EVE ghost enemies 한국어 패치

Nintendo Switch판 **EVE ghost enemies**의 비공식 한국어 패치입니다.

> [!WARNING]
> ## ⚠ 현재 배포판은 **미검수판**입니다.
> 현재 한국어 번역은 게임 전체에 대한 **최종 검수가 완료되지 않은 상태**입니다.
> 오탈자, 오역, 어색한 문장, 캐릭터 말투·호칭 불일치, 줄바꿈 또는 표시 이상, 일부 진행 관련 문제가 남아 있을 수 있습니다.
>
> 플레이 중 문제를 발견하셨다면 **GitHub의 `Issues` 탭에서 제보해 주세요.**
> 가능하면 **발생 루트 / 장면 / 문제 대사 / 스크린샷 / 재현 방법**을 함께 남겨주시면 수정에 큰 도움이 됩니다.

## 한국어화 범위

현재 패치는 다음 영역을 중심으로 한국어화되어 있습니다.

- 스토리 대사
- 화자명
- 선택지 및 일부 명령 UI
- 한국어 표시를 위한 폰트

현재 공개판은 **미검수판**이므로, 번역 품질과 전체 게임 진행에 대한 최종 검증은 계속 진행 중입니다.

## 적용 방법

### PC 에뮬레이터

1. Releases에서 **PC용 패치**를 받습니다.
2. 압축을 해제합니다.
3. 에뮬레이터에서 EVE ghost enemies의 **모드 데이터 위치**를 엽니다.
4. 패치 폴더의 `romfs`가 아래와 같은 구조가 되도록 넣습니다.

```text
<모드 폴더>
└─ romfs
   └─ data_eve3
      ├─ 01_script
      └─ font
```

같은 파일을 변경하는 기존 한글패치나 테스트 모드가 있다면 먼저 비활성화해 주세요.

### Nintendo Switch / Atmosphere

Switch용 배포판의 `01007BE0160D6000` 폴더를 SD 카드의 다음 위치에 복사합니다.

```text
atmosphere
└─ contents
   └─ 01007BE0160D6000
      └─ romfs
         └─ data_eve3
```

모드 상위 폴더에는 **Base Title ID `01007BE0160D6000`**을 사용합니다.

### Android 에뮬레이터

Android용 배포판도 다음 Title ID 구조를 사용합니다.

```text
01007BE0160D6000
└─ romfs
   └─ data_eve3
```

사용 중인 에뮬레이터의 모드 설치 방식에 맞춰 위 폴더를 적용해 주세요.
