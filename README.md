## 다운로드

최신 배포판은 이 저장소의 **Releases**에서 받을 수 있습니다.

자세한 적용 방법은 배포 파일에 포함된 `설명서.txt`를 확인해 주세요.

## 지원 게임 버전

- **EVE ghost enemies 일본판**
- **업데이트 1.02**

다른 버전에서는 정상 동작을 보장하지 않습니다.

## 한국어화 범위

현재 다음 영역이 한국어화되어 있습니다.

- 스토리 대사
- 화자명
- 선택지 및 일부 명령 UI
- 한국어 표시용 폰트

현재도 전체 대사를 순차적으로 검수하고 있으며,
검수 결과와 제보된 문제를 이후 버전에 계속 반영할 예정입니다.

## 적용 방법

1. **Releases**에서 최신 패치를 받습니다.
2. 압축 파일을 해제합니다.
3. 포함된 `설명서.txt`를 따라 패치를 적용합니다.

본 배포본에는 게임 본편 및 원본 데이터, NSP/XCI/NCA, 원본 RomFS, `prod.keys`가 포함되어 있지 않습니다.

**본 패치는 게임 원본 파일을 포함하지 않으며, 패치 파일만 제공합니다.**

## 오류 및 번역 제보

오역이나 표시 오류, 진행 문제를 발견하셨다면 **GitHub Issues**를 통해 제보해 주세요.

가능하면 다음 정보를 함께 남겨주시면 확인에 도움이 됩니다.

- 플레이 중인 루트 또는 챕터
- 발생 장면
- 문제가 있는 한국어 대사 또는 UI 문구
- 가능하면 일본어 원문
- 스크린샷
- 진행 불가나 표시 오류의 경우 재현 방법

특히 아래 문제를 확인하고 있습니다.

- 오역 / 누락 번역
- 인명·지명·용어 표기 오류
- 캐릭터 말투·호칭 불일치
- 문장 잘림 / 줄바꿈 이상
- 글자 깨짐 / 표시 오류
- 선택지 또는 메뉴 이상
- 진행 불가 / 프리징 / 장면 전환 문제
